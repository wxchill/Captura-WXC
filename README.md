# Captura WXC

基于 [MathewSachin/Captura 8.0.0](https://github.com/MathewSachin/Captura/tree/v8.0.0) 的个人定制版，适用于 Windows 10 2004+ / Windows 11 的 Intel、AMD 64 位电脑。

## 下载安装

到本仓库的 **Releases** 下载 `Captura-WXC-2026.11.06-Setup-x64.exe`，双击安装。安装包包含 FFmpeg、ffprobe、独立 Python、本地中英文 OCR 和英译中模型，截图处理不需要自行搭建 Python 环境。缺少 Visual C++ 运行库时会调用安装包内的微软安装程序，需要管理员授权。

首次使用在主页面选择屏幕、麦克风和系统音频。默认全屏、10 FPS、不缩放、音频关闭，录像保存到当前用户“文档\Captura-WXC”。打开先显示主页面，点 × 收入托盘；完全退出请使用系统托盘右键菜单。快捷键全部禁用，仅鼠标控制。

## 定制功能

- 清晰的录制状态条，分开的开始、停止按钮，以及录制结束后的保存对话框。
- 小号像素录屏桌宠：拖动、眼睛跟随鼠标、四个弧形按钮、机身 `wxc`。录制时脸部只显示时间数字，停止后恢复眼睛。
- 桌宠按钮展开不改变透明窗口尺寸和位置，像素字形与边框提前缓存。
- 截图每次手动框选，可涂鸦、提取文字、本地或联网翻译，以及将译文覆盖到原文位置。
- 单实例启动。桌宠与主页面共享录制配置。

本地翻译模型支持英文到简体中文。联网翻译使用 MyMemory，会发送待翻译的文字，可能受服务额度限制。复杂背景、公式和小字号的识别或覆盖翻译需要人工核对。

## 发布版修复

1. 修正 FFmpeg 备用路径，把可执行文件所在目录与文件名正确拼接。
2. 独立使用 `%APPDATA%\CapturaWXC` 配置目录；移动安装位置后只修复失效的编码器路径，保留其他偏好。损坏的配置会先留存再重建。
3. 另存录像先复制到目标卷的临时文件，再原子替换；失败时保留原录像及原目标文件，显示失败提示。覆盖同名文件前确认。
4. 移除固定开发目录的调试日志写入。安装包不携带个人配置、历史、录制文件、调试输出或程序备份。

详见 [验证记录](docs/VALIDATION.md) 和 [构建说明](docs/BUILD.md)。

## 源码与许可证

`extensions` 是新增功能源码，`packaging/src` 包含发布引导和保存流程修复。保存对话框、状态条、分离按钮的原始编辑源码未保留，本仓库相应文件由现有自定义程序集恢复后整理，并标明在构建说明中。

`vendor/legacy-runtime.zip` 是本次定制版所用的轻量运行文件快照；`vendor/captura-v8.0.0-source.zip` 是上游源码。当前构建使用该快照保留已有程序集及界面资源改动，**不是完全从上游源码重建所有旧程序集**。FFmpeg 和模型不提交进 Git 历史，随 Releases 安装包提供。
